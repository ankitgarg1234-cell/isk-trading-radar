No paper account, scheduler, brokerage or deployment is created or changed. This document establishes the path when historical point-in-time validation data are unavailable. It is not a claim that prospective collection has begun.

Before the first unseen observation, publish a timestamped commit freezing the selected baseline, any quality metric definitions, missing-data behavior, rankings, entry/exit/sizing/cost rules, source maps and acceptance tests.
