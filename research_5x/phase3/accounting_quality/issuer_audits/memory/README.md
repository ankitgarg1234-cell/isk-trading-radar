# Mandatory storage/memory accounting audits

Run `python3 build_audit.py` from any directory to rebuild the CSV/JSON and verification checks. It imports no production code and performs no portfolio simulation. Original facts are manually transcribed in the script; rerunning does not imply an automated reread of every external source.

The three issuer notes explain the economic exceptions and distinguish documented facts from analyst diagnostics. `quality_metrics.csv` contains quarter and annual **vintage rows**, not a statistical sample of independent investments. `source_lineage.csv` identifies the primary original document and targeted review. `inherited_release_inventory.csv` preserves all 30 Phase 2 release references and its inherited coverage limitations; new targeted review is separately identified. `timestamp_conflicts.csv` retains conflicting current submissions strings versus original accession-index times. `source_evidence.json` retains reported input facts and derived metrics. `verification_checks.json` records the actual arithmetic, missingness and lineage checks.

Blank metrics are missing sources or invalid comparisons. The packet does not turn net capital spending into gross capex, nonpositive earnings denominators into cash-conversion ratios, or WDC consolidated cash into standalone HDD cash. Company-defined FCF, CFO-minus-gross-PPE FCF and the MU equipment-contract sensitivity are separate columns. Nonrecurring gains are not subtracted from after-tax earnings without an explicit tax bridge.

This delivers source-supported case evidence, including original Q4/annual comparisons. It cannot pass the all-39-issuer accounting coverage gate, create a historical consensus series, establish a causal failure explanation, or validate any entry/holding rule. Six original MU/STX release-page snapshots are retained under `raw/` with SHA256 hashes in `download_manifest.json`; the remaining eight targeted SEC/WDC direct downloads returned HTTP403. Their numerical sections and SEC indices were reviewed through the web tool, but the original document binaries were not retained. Retrieval in2026 of a dated original page is not certification of a historical web archive. Earlier and later phase directories remain read-only.
